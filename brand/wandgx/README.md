# WandGx canonical brand assets

All files in this directory are supplied transparent PNGs with RGBA alpha.

| Asset | Use |
| --- | --- |
| `wandgx-logo-on-light.png` | Full dark logo lockup for light backgrounds |
| `wandgx-logo-on-dark.png` | Full light/silver logo lockup for dark backgrounds |
| `wandgx-mark-on-light.png` | Dark standalone WandGx mark for light backgrounds |
| `wandgx-mark-on-dark.png` | Light standalone WandGx mark for dark backgrounds |
| `wandgx-wordmark-on-light.png` | Dark standalone wordmark for light backgrounds |
| `wandgx-wordmark-on-dark.png` | Light standalone wordmark for dark backgrounds |

Use the transparent PNG directly. Do not flatten it onto a rectangle or re-export it as JPEG.
